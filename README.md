# 궁동·어은동 생존 지도

충남대와 KAIST 사이 대학가(대전 유성구 궁동·어은동)의 가게들이 10년 동안 어떻게 생기고 사라졌는지 3D로 걸어 보며 확인하는 웹이에요. 새내기가 동네를 미리 걸어 보며 거리 감각을 익히는 「새내기 탐험」 모드도 있어요.

Color Your 2026 Project (KAIST 새내기과정학부) 출품작.

## 데이터 출처
- 가게 개업·폐업: 행정안전부 인허가 정보 OpenAPI (일반음식점·휴게음식점·제과점·PC방), 공공데이터포털, 2026.10.28 기준
- 교차 검증: 소상공인시장진흥공단 상가(상권)정보 (2015.12, 2026.06), 공공데이터포털
- 건물: 국토교통부 GIS건물통합정보 (브이월드)
- 주소 좌표 확인: 브이월드 지오코더
- 도로·횡단보도: © OpenStreetMap contributors (ODbL)
- 프랜차이즈 로고: 위키백과·위키미디어 공용 (각 브랜드의 상표)

개업·폐업 시점은 인허가일자·폐업일자 기준이라, 영업자 지위승계로 주인이나 상호가 바뀐 경우가 한 기록으로 이어질 수 있어요.
